# Акцент поиска: JavaScript / Node.js

## На что делать упор в письме
- JavaScript / Node.js — практический опыт backend- и веб-разработки.
- Основной профиль — PHP/SQL/JS, то есть JS — это не «рядом», а часть core-стека.
- Сильная сторона — SQL/NoSQL и данные, интеграции, REST API.
- Домены: eCommerce, FinTech, Blockchain/Web3.
- Быстро осваиваю новый JS-стек и инструменты.

## Позиционирование
Разработчик с ядром PHP/SQL/JS, также Go. Не тестировщик.

## Чего избегать
- Не выдумывать опыт с конкретными фреймворками (React/Vue/NestJS), если их нет в профиле.
